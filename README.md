# 単語学習

用語を見て、2つの説明から正しいほうを選ぶクイズです。GitHub Pages で動く静的なページです。1ゲームは10問で、制限時間の初期値は1秒です。

## GitHub Pages で公開する

このリポジトリは、ビルドせずにルートをそのまま配信します。

1. GitHub でリポジトリを開く。無料プランで Pages を使うには、リポジトリを公開（Public）にしておく。
2. **Settings** → **Pages** を開く。
3. **Build and deployment** の Source を **Deploy from a branch** にする。
4. Branch を `main`、フォルダを `/ (root)` にして保存する。
5. 1〜2分ほどで公開される。URL は次のとおり。

https://windhole.github.io/wht-tan5pick/

`main` へ push すると、同じ設定のまま再公開される。

## ローカルで開く

`index.html` をファイルとして直接開くと、問題ファイルを読めません。このディレクトリでサーバーを立てます。

```sh
python3 -m http.server
```

ブラウザで http://127.0.0.1:8000/ を開きます。

## 遊び方

1. オープニングで問題セットを選ぶ。
2. 制限時間を 0.1秒〜10秒の範囲で変える。初期値は 1.0秒。
3. **スタート** を押す。
4. 用語の下に説明が2つ出る。正しいほうを押す。`1` キーが上、`2` キーが下。
5. 押さなくても、時間切れで次の問題へ進む。
6. 10問で結果が出る。各問の正誤、選んだ説明、正しい説明が一覧になる。

ハイスコアは問題セットごとの正解数（0〜10）です。同点のときは、制限時間が短い記録が残ります。ハイスコア、制限時間、回答ログはこのブラウザの中だけに保存され、別の端末とは共有されません。蓄積した回答は **回答ログ** から見られます。

## 問題を追加する

問題は `data/` のテキストファイルです。文字コードは UTF-8、1行が1問、区切りはタブです。

```text
# で始まる行と空行は無視される
API	ソフトウェア同士が機能を呼び出すための窓口
CPU	計算や制御を行う中央処理装置
```

説明が異なるレコードが2件以上必要です。1件だと誤答を作れません。

問題セットの一覧は `data/sets.json` です。

```json
{
  "id": "my-set",
  "title": "表示名",
  "file": "my-set.txt"
}
```

`file` は `data/` からのファイル名です。ディレクトリ区切りは使えません。

### data/ と gitignore

`data/` は `.gitignore` に入っています。自分用の問題ファイルを置いても、そのままではコミットされません。

リポジトリに最初から入っている次のファイルは、すでに追跡されているので Pages に載ります。

- `data/sets.json`
- `data/it-basics.txt`
- `data/business.txt`

新しい問題ファイルを公開するときは、無視を外して追加します。`sets.json` は追跡済みなので、編集は通常のコミットで反映されます。

```sh
git add -f data/my-set.txt
git add data/sets.json
git commit -m "Add a problem set"
git push origin main
```
