# 単語学習

用語を見て、2つの説明から正しいほうを選ぶクイズです。ローカルで `bun run dev` により動きます。1ゲームは10問で、制限時間の初期値は1秒です。

## セットアップ

[Bun](https://bun.sh) を入れます。外部パッケージのインストールは不要です。

```sh
bun run dev
```

ブラウザで http://127.0.0.1:3000/ を開きます。

## 遊び方

1. オープニングで問題セットを選ぶ。
2. 制限時間を 0.1秒〜10秒の範囲で変える。初期値は 1.0秒。
3. **スタート** を押す。
4. 用語の下に説明が2つ出る。正しいほうを押す。`1` キーが上、`2` キーが下。
5. 押さなくても、時間切れで次の問題へ進む。
6. 10問で結果が出る。各問の正誤、選んだ説明、正しい説明が一覧になる。

ハイスコアは問題セットごとの正解数（0〜10）です。同点のときは、制限時間が短い記録が残ります。ハイスコアと制限時間はこのブラウザの中だけに保存されます。

回答と正誤は `data/log.jsonl` に1行ずつ追記されます。**回答ログ** から一覧できます。このファイルは `data/` ごと gitignore されるので、リポジトリには入りません。

## 問題を追加する

問題は `data/` のテキストファイルです。文字コードは UTF-8、1行が1問、区切りはタブです。先頭の `# title:` が表示名になります。無ければ、拡張子を除いたファイル名を使います。

```text
# title: IT基礎用語
# で始まる行と空行は無視される
API	ソフトウェア同士が機能を呼び出すための窓口
CPU	計算や制御を行う中央処理装置
```

説明が異なるレコードが2件以上必要です。1件だと誤答を作れません。ファイルを置いてページを再読み込みすると、問題セットの一覧に出ます。

### data/ と gitignore

`data/` は `.gitignore` に入っています。サーバーは、コミットされていないファイルも読みます。自分用の問題を置いても、そのままではリポジトリに入りません。

リポジトリに残っているサンプルは次のとおりです。

- `data/it-basics.txt`
- `data/business.txt`

サンプル以外もリポジトリに残すときは `git add -f data/ファイル名.txt` します。
