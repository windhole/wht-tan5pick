# title: IT基礎用語
# 問題ファイル: 1行が1レコード。区切りはタブ（用語<TAB>説明）
# # で始まる行と空行は無視される

API	ソフトウェア同士が機能を呼び出すための窓口
CPU	計算や制御を行う中央処理装置
メモリ	プログラムやデータを一時的に覚えておく装置
SSD	電気的にデータを保存する補助記憶装置
URL	インターネット上の資源の場所を示す住所
HTML	ウェブページの構造を書くマークアップ言語
CSS	ウェブページの見た目を指定する仕組み
DNS	ドメイン名をIPアドレスに変換する仕組み
HTTP	ウェブで文書をやり取りする通信手順
IPアドレス	ネットワーク上の機器を識別する番号
OS	ハードウェアとアプリの橋渡しをする基本ソフト
LAN	建物や家庭など限られた範囲のネットワーク
VPN	公衆網の上に作る暗号化された専用の通信路
SQL	関係データベースを操作するための言語
JSON	データを名前と値の組で表すテキスト形式
Git	ファイルの変更履歴を記録するバージョン管理ツール
Cookie	ブラウザにサイトの小さな情報を保存する仕組み
キャッシュ	再取得を省くために手元に置いておく複製
クラウド	インターネット経由で使う計算機や保存領域
バグ	プログラムが意図と違う動きをする欠陥
