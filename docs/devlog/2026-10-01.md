## 08:00 〜 README と data/ の gitignore

### やったこと
- 使い方と GitHub Pages の公開手順を README.md に書いた
- `.gitignore` の `data/` 除外を戻した。追跡済みのサンプルはそのまま残す

### 詰まった点・気づき
- ADR-0001 で外した除外は、個人用の問題をコミットしない既存ルールだった。公開するファイルだけ `git add -f` する

### 関連ADR / コミット
- ADR-0002（ADR-0001 の gitignore 判断を取り消し）

## 13:15 〜 Bun のローカルサーバーへ切り替え

### やったこと
- GitHub Pages 向けの静的配信をやめ、`bun run dev`（`Bun.serve` と TypeScript）にした
- 問題セットは `data/*.txt` をサーバーが読む。表示名は `# title:`
- npm の依存は置かず、ブラウザ向けの束ねは Bun 同梱の `Bun.build` を使う

### 詰まった点・気づき
- `data/` は gitignore のままでよい。ローカルサーバーは無視されたファイルもディスクから読める

### 関連ADR / コミット
- ADR-0003
